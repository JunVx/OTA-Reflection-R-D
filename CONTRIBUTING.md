# Contributing

Thanks for your interest in contributing to **OTA Reflection R&D**.

## Scope for this repository

- Keep contributions aligned with the manuscript:
  - *Uncertainty Quantification and Mitigation of Residual Chamber-Reflection Effects in Wideband SISO OTA Measurements*.
- For initial setup phases, prioritize repository organization and documentation.
- Do not add replacement implementations of unpublished research algorithms unless explicitly authorized by the maintainer.

## Issues and discussions

- Use the bug report template for repository or tooling problems.
- Use the reproduction question template for method/reproducibility clarification.
- Keep reports factual and include enough context to reproduce behavior.

## Data and confidentiality

- Do not commit proprietary datasets, confidential instrument logs, credentials, or private paths.
- Clearly label synthetic examples, simulation outputs, and experimental measurements.
- When data is added, include units, normalization definitions, and provenance.

## Pull requests

- Keep changes focused and minimal.
- Update documentation when behavior or workflow changes.
- Avoid claiming manuscript reproduction unless independently verified and documented.
